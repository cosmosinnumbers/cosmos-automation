# Effetti sonori

`library.json` + `openverse/*.wav`: effetti CC0 trovati su Openverse da `tools/sfx_library.py` (workflow
`sfx-library`, mensile o "Run workflow"). Solo CC0: niente licenze con obblighi. Per ogni suono: titolo, autore,
pagina e licenza. Quando un tipo di suono non ha file CC0, `video/ytf/sfx.py` lo genera in codice.
